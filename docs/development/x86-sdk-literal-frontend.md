# Shared SDK literal-minimum handoff

Both frontends use `internal/sdkfrontend.Source.BindNumericalReads`. The root
cost query reuses the complete bounded literal CFG and actual typed source
grammar: native-word materialization/copies and literal OR carriers leading to
an immediate B/W/L/Q TEST in a declared ABIInternal bool-result function. It
produces no address, floor, instruction certificate or numerical initialization.
Ordinary fixed/indexed literal reads, incoming caller predicates, partial/raw
carriers and escapes do not request an additional original Go link.

Only a genuine predicate demand captures the existing original-linked minimum
producer, once, using the same original readonly owner and bounded context.
The producer retains the actual SDK source, complete graph/archive, linker,
CGO/profile and lifetime contracts. The explicit core binder still independently
joins its generation/seal and floor to the exact original source. The default
core numerical binder continues to refuse address-bit permission.

Successful and failed attempts are cached without replay. Every callback
boundary checks the original owned handles; a late numerical replacement or
Close permanently revokes the shared source. Operations reject reentry instead
of blocking, before invoking caller context methods. Concurrent Close marks
pending and immediately revokes the original numerical publication token,
without disposing artifacts or invoking borrowed contexts/owners. Old bound
Options cannot publish during the still-active callback. Owning cleanup releases
resources exactly once when that operation unwinds. Errors return zero Options;
pre-operation component mutation cannot revive after pointer restoration. The
query preflight retains the existing complete object-symbol inventory bound.
Cleanup order is minimum, numerical source, literal owner, ASM DATA source,
Go owners.

Numerical verification checks the publication token again after its final SDK
context callback. Readback and original Go-input joins also check it under their
existing source lock. Independent original CRC32 controls revoke at the actual
last verified callback, including both module and Go-module final guards;
verification, reports and all three APIs must return Context without output.

Independent command receipts require one actual `tool link` for a cached maps
minimum, and zero extra link/minimum attempts for repeated ordinary CRC32
binding. Complete original maps frontend tests retain two TEXTs/all DATA and
genuine mutable external AES storage; emitted objects are logical translation
evidence, not physical SDK ABIInternal calling or complete runtime execution.
The distinct no-DATA metadata-only owner and unsupported caller/entry contracts
are not added by this handoff.
